# 2026-11-01 首页迁移：沙漏粒子页作为首页

## 目标

把 `nether/projects/particle_sandglass` 的页面移植进 `personal_navigation`：

1. 沙漏页面成为首页（`index.html`）
2. 原导航首页整体保留，改为子页面（`nav.html`）
3. 原页面的部分内容（服务入口、身份、版权）进入首页

## 拆分与执行

| # | 工作 | 产物 |
| --- | --- | --- |
| 1 | 迁移运行时资源：样式、脚本、字体 | `css/sandglass.css`、`js/sandglass.js`、`assets/fonts/*.woff2` |
| 2 | 字体路径改为新目录 | `@font-face` 由 `./stencil-clone/fonts/` 改为 `../assets/fonts/` |
| 3 | 新首页：沙漏主体 + 左栏入口面板 | `index.html` |
| 4 | 原首页原样保留并加返回链接 | `nav.html` |
| 5 | 子页面返回链接样式 | `css/style.css` 新增 `#home-link` |
| 6 | 状态页返回链接改指导航页 | `status.html` |
| 7 | 文档同步 | `readme.md`、`docs/目录结构.md` |

## 设计决定

- **只迁运行时文件**：`stencil-clone/` 参考站副本、`poster*.js`、设计提示词与
  `README` 属于原项目的实验上下文，不进入导航站。
- **两套样式不合并**：沙漏是固定视口的深色构图（`html, body { overflow: hidden }`），
  导航页是三态主题的可滚动卡片页。合并会破坏两边，故以文件为边界隔离。
- **首页恒为深色**：沙漏的配色来自 `--st-*` 令牌（黑底 + 青 / 紫），不接入
  `--accent` 主题体系，首页因此不放主题切换按钮；主题切换保留在导航页 / 状态页。
- **入口面板位置**：桌面放在左上「实验标签」之下的空白带，手机放在顶部空白带，
  均用绝对定位，与已有的 `study-header` / `flow-marker` / `landing-foot` /
  `landing-meta` 互不重叠（已在 1440×900、390×844 实测框选校验）。
- **沿用原页面的服务文案与链接**：openlist、jellyfin、status.html 三个入口 +
  「全部链接与项目」指向 `nav.html`。
- **CSP 兼容**：首页不含内联脚本 / 内联样式，字体与脚本均为同源文件，符合
  `_headers` 的 `default-src 'none'; script-src 'self'; font-src 'self'`。

## 验证

本地 `python -m http.server` + Chromium 实测：

- 1440×900：`#stage` 进入 `data-state="running"`、`data-renderer="webgl2"`，
  计时器 `T+ 00:0x` 递增；面板 300×236 位于 `(65,143)`，与 header / foot / meta /
  flow-marker 无重叠
- 390×844：面板宽度 `calc(100% - 2×24px)`，竖排紧凑列表，与 header / foot / meta /
  flow-marker 无重叠，`scrollWidth === innerWidth`（无横向溢出）
- 字体 `Geist` / `Instrument Sans` / `Ioskeley Mono Term` 均为 `loaded`
- 交互：面板「全部链接与项目」→ `nav.html`；`nav.html` 左上「← 首页」→ `index.html`；
  `Pause` 按钮与 `Space` 快捷键在 paused / running 之间正确切换
- 控制台无报错

## 后续注意

- 首页动画在页面隐藏、`prefers-reduced-motion`、WebGL 上下文丢失时都会停帧或降级，
  修改 `sandglass.js` 时需保持这些分支。
- `nav.html` 与 `status.html` 内的返回链接若调整层级，需同时改 `#home-link` /
  `status-actions` 的相对路径。

### 底部覆写的第二次调整

第一版只把底座边距收到 `~0.6–1vh`，椭圆最低点刚好越过下边缘，但低于 `base*0.965`
的填充区仍有约 25px 黑带。改为把底座整体推到视口外
（`base = height - tipY + max(10, height*0.022)`），让下半腔轮廓、沙堆与底座都被
下边缘裁切：

| 截图区域（1800×1125，x∈[700,1400]） | 改动前 | 改动后 |
| --- | --- | --- |
| 最底 1px 行亮像素占比 | 0.0% | 23.1% |
| 距底 10px | 0.0% | 23.4% |
| 距底 30px | 2.9% | 18.3% |

验证：1440×900 与 390×844 下服务星标 / 字标 / 版权 / 按钮 / meta 互不重叠，
三个星标与「全部链接与项目」的跳转正常，Pause 与 `Space` 正常；
模拟 `prefers-reduced-motion: reduce` 时 Pause 变为不可用的 `Still` 且不启动动画。

| # | 反馈 | 落实 |
