# 目录结构

部署目标：Cloudflare Worker `personal-navigation`（静态资源 + 单个 `/api/status` 路由）。
静态文件在 `public/`，Worker 入口在 `src/`，协议由 `wrangler.jsonc` 显式声明。

```text
personal_navigation/
├── public/                   # 静态资源根目录，原样发布到站点根
│   ├── index.html            # 首页：粒子沙漏 + 服务星标 + 全部链接入口
│   ├── nav.html              # 导航页（原首页）：关于 / 项目 / 服务卡片
│   ├── status.html           # 服务状态页
│   ├── _headers              # 响应头：CSP / HSTS / 缓存策略
│   ├── css/
│   │   ├── sandglass.css     # 首页样式（Stencil 风格，含服务星标与底栏）
│   │   └── style.css         # 导航页 / 状态页样式（含深浅色变量、响应式）
│   ├── js/
│   │   ├── sandglass.js      # 首页粒子沙漏（WebGL2 + Canvas 2D 降级）
│   │   └── theme.js          # 主题切换（自动 / 浅色 / 深色）与头像切换
│   └── assets/
│       ├── fonts/            # 首页字体：Geist / Instrument Sans / Ioskeley Mono
│       ├── headimg/          # 头像（浅色 blue / 深色 dark 等）
│       └── websiteimg/       # 站点与服务图标
├── src/
│   ├── index.js              # Worker 入口：/ 映射 index.html，/api/* 路由分发
│   └── status.js             # /api/status：代理 UptimeRobot API
├── wrangler.jsonc            # Worker 配置：main / assets / html_handling / run_worker_first
├── .gitignore
├── readme.md                 # 项目说明
└── docs/
    ├── 个人导航页——项目构想与开发计划.md
    ├── 目录结构.md
    └── 开发日志/
        ├── 2026-11-01-首页迁移.md
        └── 2026-11-01-迁移到-Workers-修复构建失败.md
```

## 说明

- 首页来自 `particle_sandglass` 项目，只迁移了运行时需要的文件：
  `index.html`、`css/sandglass.css`、`js/sandglass.js` 与三个 `.woff2` 字体；
  原项目的参考站副本（`stencil-clone/`）与设计提示词没有引入。
- `nav.html` 是原 `index.html` 的完整内容（卡片、头像、主题切换脚本均未改动），
  仅新增左上角「返回首页」链接；`status.html` 的返回链接同步指向 `nav.html`。
- 两套样式互不共享：`sandglass.css` 为固定视口的深色构图，`style.css` 保留
  原有的浅 / 深主题体系，因此首页不提供主题切换按钮。
- `public/` 是静态资源根：Worker 的 `assets.directory` 指向它，目录内文件即站点
  根下的同名路径（`public/nav.html` → `/nav.html`）。`docs/`、`readme.md`、
  `src/`、`wrangler.jsonc` 不会作为静态资源发布。
- `public/_headers` 是静态资源约定文件，用于配置响应头，无需构建步骤。
- `html_handling: "none"`：`/nav.html`、`/status.html` 按字面路径直接返回，
  不会被重写成 `/nav`、`/status`。这是必须的——`_headers` 里针对 `/status.html`
  的 `connect-src 'self'` 规则按字面路径匹配，一旦重写，状态页的 `fetch('/api/status')`
  会被 `default-src 'none'; connect-src 'none'` 拦掉。
- `/` 没有对应文件，因此 `run_worker_first` 同时包含 `/`，由 `src/index.js`
  显式转发到 `/index.html`；其余路径由静态资源直接返回，不经过 Worker。
- 项目没有 `package.json`，也没有任何构建产物：`wrangler.jsonc` 让 Workers Builds
  跳过「自动探测」，直接 `wrangler deploy`。
- 已弃用的 PHP 版状态页（`index.php`）及其缓存文件已从版本控制中移除，并在
  `.gitignore` 中忽略。
